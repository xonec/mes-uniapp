# 编码风格

## 代码风格

- 页面设计务必关注元素的布局和交互,避免使用复杂的样式规则,满足需求的前提下,尽可能地使用 `flex`、`grid` 布局,不轻易使用确切的 px 值,尽量使用百分比(优先)或 rem 单位,必要时设置 `min-width` 或 `min-height` 属性,避免元素极小情况,内容显示不全,以响应式布局为目标。
- 自定义主题的需求,不要轻易使用准确的颜色值(如 #000000、#ffffff、rgb(0,0,0)、rgba(0, 0, 0, 1) 等),尽量使用 `uni.scss` 中定义的颜色变量(`$primary`、`$primary-soft`、`$muted`、`$line`、`$surface`、`$warning`、`$danger`)。
- 常量全大写,并使用 `_` 连接单词,例如:`MAX_COLOR_VALUE = 255`。
- 文件和文件夹使用 `-` 连接,例如:`data-source`,`.vue` 组件首字母大写,例如:`DataSource.vue`。
- 构造函数首字母大写,例如:`DataSource`。
- 文件引入优先使用 workspace 中已有的别名,例如:`@`(指向项目根目录)。

## 依赖要求

本工程为 HBuilderX 直编的 uni-app 项目,没有 npm 依赖层(无 `package.json`、`node_modules`、lockfile),依赖统一通过项目根目录 `mes-uniapp/` 下的 `uni_modules/` 与 `libs/` 管理,不引入 npm。

## 注释规范

公共函数必须包含 JSDoc 注释
