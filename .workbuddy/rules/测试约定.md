# 测试约定

非核心业务的功能模块无需创建单元测试用例,但是核心功能(如:包材计算引擎 `utils/calc.js`、云函数 `production-records`、云函数公共模块 `mes-common`、帆软抓取 `utils/fr-fetch.js`)必须包含测试用例,使用 Node 内置 `node:assert` 编写的自建测试脚本(无第三方测试框架),测试脚本统一放在 `tests/` 目录下,命名为 `*.test.mjs` / `*.test.cjs`,运行方式:

```bash
node --experimental-detect-module tests/calc.test.mjs
node tests/mes-common.test.cjs
node tests/production-records.test.cjs
```
